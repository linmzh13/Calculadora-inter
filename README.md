# Calculadora en Python

## Descripción

Este proyecto consiste en una calculadora básica desarrollada en Python utilizando la librería Tkinter para crear una interfaz gráfica. El programa permite realizar operaciones matemáticas sencillas por medio de botones.

La calculadora está organizada utilizando programación orientada a objetos, mediante una clase llamada `Calculadora`, que contiene los atributos y métodos necesarios para su funcionamiento.

## Funciones

La calculadora permite realizar las siguientes acciones:

- Ingresar números del 0 al 9.
- Realizar sumas, restas, multiplicaciones y divisiones.
- Utilizar números decimales.
- Mostrar el resultado de una operación al presionar el botón `=`.
- Borrar el contenido de la pantalla con el botón `C`.
- Mostrar un mensaje de error cuando una operación no se puede realizar correctamente.

## Cómo ejecutar el programa

1. Descargar o clonar el proyecto.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir una terminal.
4. Ejecutar el archivo: interfaz.py
5. Se abrirá la ventana de la calculadora y se podrá comenzar a utilizar.
